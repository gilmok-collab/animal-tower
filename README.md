# 동물마을 하늘탑 🐾

초등학생을 위한 타워 점프 웹게임. 동물 친구를 골라 구름 꼭대기 깃발까지 올라갑니다.
설치 없이 브라우저에서 바로 플레이할 수 있어요.

👉 **[놀러 가기](https://gilmok-collab.github.io/animal-tower/)**

## 두 가지 버전

| | 2D 하늘탑 | 3D 하늘탑 |
|---|---|---|
| 보기 | 옆에서 보는 화면 | 탑을 도는 3D 화면 |
| 조작 | ◀ ▶ 버튼 + 점프 | 조이스틱(전방향) + 시점 회전 + 점프 |
| 특징 | 대포·풍선·바람 구간 | 회전 발판·별 파워·천사 날개 |

## 3D 모험 — 별 조각을 찾아서

꺼져 버린 하늘탑 별램프를 다시 켜려고, 다섯 층에 흩어진 별 조각을 모읍니다.

| | 스테이지 | 그곳의 장치 |
|---|---|---|
| 1 | 🌳 숲속 마을 | 계단 · 통나무 다리 · 사다리 · 비탈길 · 나무 위 오두막 |
| 2 | 🌊 물보라 항구 | 출렁이는 부교 · 돛대 사다리 · 밧줄 다리 · 도르래 승강기 · 등대 |
| 3 | ❄️ 눈꽃 산장 | 미끄러운 얼음 · 눈보라 · 눈사람 · 고드름 사다리 |
| 4 | 🌙 별빛 전망대 | 빙글빙글 회전 발판 · 공중 외줄 · 밟으면 켜지는 반딧불 길 |
| 5 | 🚀 구름 천문대 | 떠다니는 구름 섬 · 대포 · 은하수 다리 · 그리고 까망이 |

| 6 | 🗼 끝없는 하늘탑 | 숲에서 우주까지 한 번에 오르는 보너스 도전 |

다섯 조각을 모두 모으면 별램프에 불이 켜지고 동물마을의 밤이 돌아옵니다.
클리어 화면의 **다음 단계로 ▶** 버튼으로 바로 이어서 놀 수 있어요.

## 함께 들어 있는 것

- 동물 친구 6명 — 각자 특기가 달라요 (높이 점프, 빠른 발, 하트 +1, 활공, 도토리 자석)
- 난이도 3단계, 하트와 깃발 체크포인트, 별 3개 평가와 기록 저장
- 발판 종류: 이동 · 번개 · 엘리베이터 · 얼음 · 사라지는 구름 · 통통/슈퍼 점프대 · 대포
- 🌰 도토리 모으기, 🐝 벌 피하기, 🌋 용암 모드(선택)
- 올라갈수록 바뀌는 풍경: 숲 → 바다 → 눈 → 밤하늘 → 우주
- 효과음과 배경음악 (웹오디오로 직접 연주 — 음원 파일 없음)

## 만든 방식

- 파일 하나로 끝나는 순수 HTML + JavaScript (빌드 도구 없음)
- 2D는 Canvas 2D, 3D는 [three.js](https://threejs.org) r128 (MIT) — 파일 안에 포함해 인터넷 없이도 실행
- 휴대폰 우선: 큰 터치 버튼, 안전 영역 대응, 화면 꺼짐 방지, 홈 화면 추가 지원

## 직접 열어보려면

`index.html`을 브라우저로 열면 됩니다. 서버가 필요 없어요.
